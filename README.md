## 先分清两条计费线，再谈充值

很多人以为 Claude Code 是一个单独收费的产品，其实不是。它有两条计费线，能不能用人民币，取决于你走哪一条。

### 订阅线：Claude Pro 自带额度

订阅 Claude Pro（官方价 **$20/月**）就附带 Claude Code 的使用额度，日常写代码基本够用。目前 Free 和 Pro 的默认模型是 Sonnet 5，更复杂的长周期任务还有 Fable 5 这类旗舰模型可选，具体可用范围随账号和套餐变化。

用量不够还有 Max 两档：Max 5× 大约是 5 倍 Pro 会话用量（$100/月），Max 20× 大约是 20 倍（$200/月）。注意即使是 Max，也仍受会话和周期限额，“包月无限用”是不存在的。

### API 线：按 token 计费

Claude Code 的命令行版（CLI）默认消耗 API 额度，要在 Anthropic 的 API 控制台预充值，用多少扣多少。这条线只认海外卡，没有激活码可以买，是人民币最难进去的一条。

顺带提醒：Claude 网页、Claude Code 和 API 的上下文与用量规则并不相同，也会随套餐调整，别拿一边的认知直接套另一边。

> 一句话记住：走 Pro 订阅，人民币就有解；走 CLI 的 API 计费，基本得靠海外卡。苹果手机能搞定前者，搞不定后者。

## 国内卡在官方页面为什么总被拒

Anthropic 在中国大陆没有官方支付渠道，风控策略也偏严格。国内卡被拒，通常逃不出这几种情况：

- 卡 BIN 属于中国大陆（62 开头的银联卡，以及国内发行的 4xx、5xx 卡头），直接被拦截
- 银行端 3D Secure 验证失败，国内多数卡没有开通海外 3DS
- 账单地址和 IP 所在地区差异太大，触发风控
- 用的机场节点 IP 信誉太差，被支付通道判定为高风险
- 同一张卡短时间内被多次拒付，进了黑名单
- 卡余额不足，或单笔限额低于 $20

所以哪怕你手里有一张全币种信用卡，也可能在最后一步掉链子。这也是“换一张美国本地虚拟卡”能解决大部分付款失败问题的原因——美国卡 BIN 加美国账单地址，在支付风控眼里和本地用户没什么区别。

## 常见问题

### Claude Code 本身多少钱？

它不单独标价。订 Claude Pro 是 $20/月，自带额度；Max 档 $100–$200/月，额度更高；走 API 则按 token 用量计费，用多少扣多少。

### 用人民币开的 Pro，Claude Code 能正常用吗？

能。Pro 订阅包含 Claude Code 的使用额度，日常开发够用。只是不是无限量，重度使用会碰到上限，到顶了要么等额度恢复，要么升 Max。

### 人民币付款会封号吗？

走激活码、虚拟卡这类“自己在官方页面操作”的方式，风险比较低。真正危险的是把账号密码交给别人代登录，那种无论多便宜都别碰。再配合前面说的养号和稳定网络，基本不用太焦虑。

### iPhone 能买 Claude Code 吗？

订阅那条线可以：App 内订 Pro，额度照常用。但电脑上敲命令的 CLI 走 API 计费，App Store 里买不到，苹果手机帮不上这个忙。

### 付款失败怎么排查？

对照前面的原因清单逐项检查：卡 BIN 是不是国内、3DS 有没有通过、账单地址和 IP 是否一致、节点信誉如何。同一张卡被拒几次就换一张，别反复试——试得越多，越容易进黑名单。

### 为什么 Anthropic 不直接收人民币？

Anthropic 是美国公司，面向全球用美元结算，没有在国内开通本地支付通道。大部分海外 AI 产品都是这个情况，不是针对谁。
